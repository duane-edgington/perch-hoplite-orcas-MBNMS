Listen: killer whales and their neighbors on the MARS hydrophone

MBARI MARS cabled hydrophone, 891 m depth, Monterey Canyon · from perch-hoplite-orcas-MBNMS

A few confirmed examples of each class, to give an ear for what the labels contain. Each is shown twice: the 5-second window the classifier scores, and 30 seconds of surrounding context with that window marked. Listen to both. The context answers questions the window cannot — whether a call is part of one animal's bout, whether it differs from what surrounds it, whether it stands alone, and whether ship noise is masking it. Audio is peak-normalized for playback; the raw recordings are far too quiet to hear.

Ship noise — 3 of 67 confirmed windows

Vessel noise. Broadband and mechanical, with none of the tonal structure biological calls show. In this dataset it sometimes correlates positively with orca presence: vessels arrive once orcas are seen.

Ship noise — 4 April 2018

Broadband and mechanical. Worth hearing because it is what masks biological calls — one of the questions the context panel is there to answer.

Edgington; humpback labels verified by J. P. Ryan. Raw recordings are free and public via the AWS Open Data registry (Pacific Ocean Sound). Spectrograms use the same code and settings as the project's annotation interface — mel, viridis, 80 dB range. See the repository and DOI 10.5281/zenodo.22574816.
